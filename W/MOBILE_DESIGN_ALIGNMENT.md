# PawCruz Mobile Design Alignment

The Pet Owner and Veterinarian modules are standardized around the same visual system:

- Page background: `#f7fbfc` / very light aqua gradient
- Main header: PawCruz dark blue gradient with `#63B6C5` secondary band
- Primary action: `#447C99`
- Primary heading: `#24566d`
- Muted text: `#5d7b91` / `#78909b`
- Cards: `#fcfeff`, 22px radius, `#dceef8` border
- Inputs: `#fbfdfe`, 14px radius, `#cee2e9` border
- Standard horizontal page padding: 18px
- Buttons: 14–16px radius, bold white text for primary actions
- Status badges remain semantically colored but use pill geometry consistently

Appointment and Messaging were specifically normalized to these values. Legacy Veterinarian design files were also updated so any fallback/imported screen does not reintroduce the older inconsistent palette.
